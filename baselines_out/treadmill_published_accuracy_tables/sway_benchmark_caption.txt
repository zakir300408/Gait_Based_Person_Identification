Trunk-sway identification benchmark. All panels use the same five model rows, with PRISM-Gait shown first. Each dumbbell links a benchmark model's accuracy (gray circle; adjacent value) to the PRISM-Gait reference (teal diamond). Labels to the right of the PRISM-Gait endpoint report the improvement in percentage points and the Holm-adjusted significance level. Pairwise comparisons used two-sided paired Wilcoxon signed-rank tests with Pratt handling of zero differences for participant window accuracies and exact two-sided McNemar tests for paired trial decisions. Holm adjustment was applied across the four PRISM-Gait-versus-comparator tests within each panel. Small sway: n = 61 paired trials; large sway: n = 59 paired trials. * P < .05; ** P < .01; *** P < .001; ns, not significant.
