## Results retained in prose instead of tables

- Identification-rank robustness remains in its figure. The Results text only
  needs the selected Rank-1 endpoints and the corresponding significance
  statements.
- Computational cost is concise enough for prose: PRISM-Gait required 18.39 s
  for registration and 14.49 ms median online inference (16.65 ms p95) for a
  2-s window. The first-decision p95 was 2.029 s with 1-s updates.
- The former treadmill demographics table was merged into Table 1.

## Statistical boundaries

- Window-level sway tests use paired participant summaries; overlapping windows
  are not treated as independent inferential units.
- Trial-level sway tests use paired exact McNemar comparisons.
- Ablation inference uses paired participant-level Wilcoxon tests.
- Reported adjusted p-values are the exact Holm-adjusted values stored by the
  current final-figure workflows.
- The verification operating threshold is selected on non-sway development
  participants at a 0.1% FAR target and frozen for disjoint sway participants.
- EER and fixed-threshold FAR/FRR describe different operating questions and
  are kept in separate columns.
- Table 2 combines the plotted small- and large-sway window accuracies with
  enrolled verification, subject-disjoint open-set EER, and fixed-threshold
  FAR/FRR for all six matched models using five common folds.
- Table 3 reports the WHU-Gait Dataset #3 and OU-ISIR benchmark accuracies.
  Its evidence column separates quoted published values from local runs.

## External dataset metadata sources

- WHU-Gait Dataset #3: Zou et al. (2020), *Deep Learning-Based Gait
  Recognition Using Smartphones in the Wild*. The paper reports 118
  participants, 50-Hz accelerometer and gyroscope signals, 128-sample
  windows with 64-sample overlap, unrestricted phone placement, and the
  official 26,283/2,991 train/test split. Age and sex are not reported.
- OU-ISIR: the official Osaka University inertial-gait database page reports
  a 2011 five-day Tokyo collection, 100-Hz waist-mounted sensors, and a
  744-participant center-IMUZ level-walking subset (389 male, 355 female;
  age 2-78 y). Zou et al. (2020) document the evaluated 745-label
  preprocessing and 13,212/1,409 train/test windows. Keep the 744-versus-745
  distinction explicit unless a subject-level mapping is recovered.

## Terminology

Use `PRISM-Gait`, `MiniROCKET`, `MultiROCKET`, `WHU-Gait`, `Core + CDKC`,
and `Core + HCGF` consistently. PKD and PHCF are legacy implementation names
for the manuscript terms CDKC and HCGF.

The preview PDF is for layout review only. Insert the individual `.tex`
snippets into the manuscript and retain the matching CSVs with the
reproducibility release.

The snippets require the LaTeX packages `booktabs`, `adjustbox`, `array`,
`graphicx`, and `amsmath`.
