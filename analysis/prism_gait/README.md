# PRISM-Gait implementation

This folder contains the authors' PRISM-Gait code.

| File | Purpose |
|---|---|
| `temporal_features.py` | raw, first-difference, and second-difference MiniROCKET branches |
| `cdkc.py` | competitive dilated-kernel coding |
| `hcgf.py` | harmonic-covariance gait features |
| `verification.py` | feature fusion, Ridge classification, and verification |
| `ablation.py` | component ablation |
| `architecture_selection.py` | architecture selection |
| `window_duration.py` | window-duration analysis |
| `nested_selection.py` | participant-level nested selection |
| `participant_accuracy.py` | participant-condition accuracy export |
